# @bsil/schemas

Generated Zod validation schemas for the `published` Prisma schema.

## Generated code

`src/generated/` is auto-generated by `zod-prisma-types` (configured in `prisma/schema.prisma`). **Do not edit these files by hand.**

## Regenerating

Edit `prisma/schema.prisma`, then run:

```bash
make data/prisma   # diffs schema, generates migration, regenerates Prisma client + Zod schemas
```

## Exports

Zod schemas for Provider, CareType, FeeRate, AdditionalCharge, WaitingListEntry, CareTypeNote, BoundingBox.

## Validation

```bash
npm run validate -w @bsil/schemas
```

Validates all published providers against the schemas and writes results into `metadata.validation`. Requires a running Postgres instance.

## Build

```bash
npm run build -w @bsil/schemas   # outputs to dist/
```
