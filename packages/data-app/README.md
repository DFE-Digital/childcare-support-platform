# BSIL Data Explorer

Internal Dash dashboard for exploring data quality across the provider dataset.

## Stack

Python, Dash, Dash Bootstrap Components, Dash Tabulator, Pandas, PyArrow

## Layout

Three-panel view — map, treemap, and field bar charts — with a filterable provider table and detail modal.

## Data

Reads from exported parquet and JSON files (generated by the data pipeline's export jobs).

## Running

```bash
make app/dash-up   # runs outside Docker, on localhost
```

This creates a local Python virtualenv on first run and starts the Dash server.

**Not deployed in production** — internal tool only.
